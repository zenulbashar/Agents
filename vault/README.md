# Foundry Vault - the shared brain

This is an **Obsidian vault**: open this `vault/` folder directly in Obsidian (or edit
the Markdown by hand). It is the company's shared brain - every agent reads it for
canon and writes durable knowledge here, and the [[what-is-foundry|brain agent]] curates it.

## Conventions

- **Wikilinks:** link notes with `[[Note Name]]`. Backlinks build the graph.
- **Tags:** `#business/prompt2eat`, `#policy`, `#skill`, `#industry`, `#decision`.
- **Folders (numbered so they sort):**
  - `00-inbox/` - unfiled captures; the brain files them.
  - `10-knowledge/` - how-tos, canon, runbooks.
  - `20-decisions/` - ADRs (mirror of the append-only decision log).
  - `30-skills/` - what the company can do; learning notes.
  - `40-industry/` - AI-industry watch (kept by the [[ai-industry-watch|learning-officer]]).
  - `50-businesses/` - canon per business ([[prompt2eat]], [[roster]], [[zaleit]]).
  - `daily/` - daily notes.
  - `templates/` - note + ADR templates.
- **Start here:** [[MOC]] (map of content).

## Rules (from config/policies.yaml)

- Personal notes are free; **editing shared canon is executive-gated**.
- **Never** put secrets or customer PII in the vault.
- When in doubt, ask the brain agent before acting - see [[how-to-ask-the-brain]].
- Every claim in canon should be **cited**; uncited != canon.
