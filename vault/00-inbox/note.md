The Support Agent at Foundry is responsible for:  
1. **Triage & Resolution** – Answering support tickets, using the knowledge base to resolve customer issues efficiently.  
2. **Bug Reproduction** – Identifying and filing clean bug reports for engineering teams to address technical problems.  
3. **Escalation Management** – Handling complex or high-risk cases by escalating through a clear chain of command (e.g., COO, operator) when needed.  

Decision authority is limited: the agent can close standard tickets independently but requires explicit approval from COO before performing any side-effecting actions like reading secrets, modifying policies, sending external communications, or handling sensitive billing/legal matters.
