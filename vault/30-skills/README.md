# Skills catalogue

#skill

What the company can currently do. Two layers:

- **Slash commands** (`skills/` in the repo): `/foundry:agents:*` (one per agent),
  `/foundry:workflow:*` (the loop), `/foundry:power:*` (guard, careful, eval, ...).
- **Learning notes:** when an agent studies something in its free time, it drops a
  note here so the whole company benefits.

Proposing a **new** skill/tool is a human gate - the [[ai-industry-watch|learning-officer]]
writes the proposal; the operator approves; then it is built and listed here.
