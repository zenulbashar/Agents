# Cowork / agent weekly playbook

Run every Monday (Cowork now; foundryd on a schedule later). Generates the week's
content into the review queue - **posts nothing** (it holds no keys).

```
Weekly marketing batch for prompt2eat (+ Roster piggyback).

1. Read brand-voice.md, content-pillars.md, guardrails.md, approved-proof.md.
2. In the Sheet 'social' tab, report last week: what posted, what errored, what is stuck in review.
3. Generate 14 X posts (2/day, no URLs, one row flagged link_post) and 7 Instagram captions
   (1/day, pick image_url from /marketing/ templates), across the five pillars, scheduled across
   the week Brisbane time. status=review.
4. Draft this week's newsletter into 'newsletter' (status=review): one prompt2eat lead story,
   one Roster section, one local hospitality note. Subject under 50 chars.
5. Research 10 new QLD hospitality venues from public sites for 'outreach': venue, contact
   name/role if published, email, source_url, one-line why_relevant, and a personalised 90-word
   draft per outreach-rules.md. status=review. Skip any site requesting no marketing contact.
6. Video batch: capture + render this week's 2 demo clips under the guardrails; upload MP4s to
   the R2 bucket; add rows channel=ig_reel and channel=tiktok, video_url set, status=review.
   Never edit brand.ts or the brand components without operator approval.
7. End with a one-screen summary of everything awaiting approval.

You have NO API keys and must not post or send anything directly.
```

Your Monday job: skim, edit anything off, flip `review -> approved`. Done. ~10 minutes.
